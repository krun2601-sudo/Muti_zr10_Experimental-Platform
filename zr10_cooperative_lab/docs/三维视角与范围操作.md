# 三维视角与范围操作（2026-09-09）

本次只更新三维面板的显示和交互。Python设备控制、识别、算法、定位、CSV记录及现有现场配置未修改。已经运行的控制中心直接刷新浏览器页面即可加载，无需安装新依赖。

## 调整空间大小

点击三维面板右上角的“范围设置”。左边是**坐标空间显示范围**：输入X、Y、Z的最小/最大坐标，点击“应用显示范围”，坐标框和取景就会更新。单位为米，可以设置小数。它只改变显示，运行实验时也可操作；框外的数据仍保留，不会改变定位或覆盖计算。

快捷聚焦按钮的用途：

- **设备群**：只按照参与实验的设备位置确定坐标框与取景，不受远处ROI和长视锥影响。设备间距变小时网格会同步缩小，不再保持至少50米。
- **选中设备**：聚焦右侧控制面板当前选中的设备及其附近；查看单台角度和局部视场时使用。
- **观测区域**：取景到任务ROI。
- **全部**：按点击时的设备、区域、视场和定位点取景。随后遥测刷新不会自动把视角拉回中心；需要重新适应最新全景时再点一次。

例如设备摆在几米内，可把显示范围设为 `X=[-5,5]、Y=[-5,5]、Z=[0,8]`；这是显示示例，实际设备坐标仍使用你的测量输入。

视场显示长度仍由面板底部原来的输入框控制，和坐标空间范围分别调整。设备附近查看时，可以把该长度改为10米等合适数值。

## 调整任务观测区域

“范围设置”右侧的**任务观测区域ROI**输入框直接对应 `policy.roi.x/y/z`。结束实验后填写范围并点击“应用观测区域”，使用原有配置校验流程应用，三维图随即聚焦新区域。实验进行中该表单锁定。

应用后如需下次继续使用，在原“实验配置”选项卡点击“保存配置文件”，下次运行指定保存的YAML。修改ROI不会自动改写预定扫描点：使用固定 `scan_points_m` 时这些点仍保留；要随ROI生成网格，按原算法接口设置 `scan_points_m: null`。若“实验配置”页已有未应用编辑，先处理这些编辑再从三维面板应用ROI。

## 放大后的移动

| 操作 | 效果 |
|---|---|
| 点击“平移”，再按住左键拖动 | 在屏幕平面自由拖动画面 |
| 按住右键拖动 | 随时平移，不必切换模式 |
| 点击“旋转”，再按住左键拖动 | 围绕当前旋转中心观察 |
| 鼠标指向位置后滚动滚轮 | 朝鼠标位置缩放，不再只向画面中心缩放 |
| 右下角方向按钮 | 向上下左右移动画面 |
| 点击画布，再按方向键 | 键盘平移；按住Shift加速 |
| 右下角＋/−，或画布获得焦点后按＋/− | 放大、缩小 |
| 双击设备 | 把旋转中心移到该设备 |
| 双击空白处 | 在当前焦点所在的屏幕平面设置新旋转中心 |
| 俯视 / 复位 | 按当前显示范围恢复俯视 / 透视取景 |

平移会同时移动相机和旋转中心，之后旋转不会弹回原场地中心。下方文字显示旋转中心坐标和视距。触摸设备可选择“平移”后单指拖动，双指缩放/平移。

显示范围与拖动方式会在同一浏览器标签会话中记住，刷新后保留；关闭标签或重启服务使用新端口时可能重置。任务ROI的长期保存使用YAML，不依赖浏览器偏好。

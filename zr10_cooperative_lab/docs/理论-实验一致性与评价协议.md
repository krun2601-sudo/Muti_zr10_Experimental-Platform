# 理论—实验一致性与评价协议

> 适用分支：`research/ecp-rh-experiments`  
> 目的：保证论文中的每个主要方法主张都有可观测证据，并避免用与理论无关的漂亮结果代替验证。

## 1. 核心原则

1. 理论结论只在其假设范围内表述；实验用于检查趋势、适用范围和工程后果，不称为“证明定理”。
2. 发现失败与发现后的连续监视必须分开统计。未发现目标不能因为 `total_loss_s=0` 而得到虚假的好成绩。
3. 所有非学习 baseline 使用相同虚拟世界、信息条件、执行限制和随机种子；参数化 baseline 只在 validation split 上选择参数。
4. MAPPO / Safe-MAPPO 的 actor observation 不含真值；训练 reward/cost 可以使用隐藏真值做 privileged supervision，但测试只报告统一 evaluator 指标。
5. `sim` 与 `mirror` 的论文任务世界保持一致。真实 ZR10 在 mirror 中仅执行动作；真实反馈用于执行诊断，不改变目标发现或论文主指标。

## 3. 发现与连续监视的评价定义

### 3.1 发现

对进入 ROI 的目标均计入 `research_entered_target_count`。若整个在区间内未建立匿名 track，则计入：

- `research_missed_target_count`；
- `research_missed_target_rate`。

发现延迟同时报告：

- observed detection delay：只对已发现目标；
- censored detection delay：未发现目标用其已观察到的在区间时长作为保守下界。

因此主比较首先看 missed-target rate，再看 censored delay；不能先用 post-discovery loss 选择 baseline。

### 3.2 连续监视

连续监视义务从目标被发现后开始，直到离开 ROI。报告：

- `research_monitor_visible_ratio`；
- `research_total_loss_s`；
- `research_max_loss_gap_s`；
- loss episode count。

这些量不能替代发现指标。

## 4. 基线公平性协议

### 4.1 非学习方法

`fixed_scan`, `greedy`, `weighted_rh`, `classical_ptz`, `info_planner`, `ssm_belief`, `ecprh` 在测试时必须共享：

- 相同 scenario YAML；
- 相同 seed；
- 相同目标真值与检测随机化规则；
- 相同 A/E/Zoom 限制；
- 相同执行 simulator；
- 相同决策机会；
- 主动规划类方法使用同一 `RiskAwarePrimitiveFactory`。

`weighted_rh/classical_ptz/info_planner/ssm_belief` 均采用 validation-only 参数选择，且每种方法最多评估相同数量的参数组合。测试集结果不得反向调整参数。

### 4.2 学习方法

- train scenarios/seeds 与 validation/test 完全分离；
- 模型选择只看 validation；
- test checkpoint 冻结；
- actor observation 不含 truth ID/position；
- privileged truth 只允许进入训练 reward/cost 和统一 evaluator；
- Safe-MAPPO cost 同时惩罚 active-but-undiscovered 和 discovered-but-not-visible，避免“回避发现”的漏洞。

## 5. 消融协议

每个消融原则上只改变一个因素：

| 消融 | 唯一主要变化 | simulator 是否保持不变 |
|---|---|---|
| `no_uncertainty` | chance envelope 中不使用 belief covariance | 是 |
| `no_overlap` | 关闭 handover overlap objective | 是 |
| `fixed_zoom` | 限制候选 Zoom | 是 |
| `short_horizon` | 缩短预测时域 | 是 |
| `no_event_replan` | 只周期重规划 | 是 |
| `no_execution_model` | planner 假设无 transition time | **是**，用于暴露模型缺失后果 |
| `no_shared_fov` | 每候选最多一个 target | 是 |

如果某消融同时改变两个以上机制，不能据此单独归因某一模块贡献。

## 6. 统计协议

主测试采用相同 `(scenario, seed)` 配对：

- paired bootstrap 95% CI；
- Wilcoxon signed-rank；
- Holm 多重比较校正；
- 报告 paired mean/median delta 和 win rate；
- 同时输出 overall 与 per-scenario 统计。

失败 run 留在 `index.csv`，不能静默删除。统计文件只聚合完成 run，但必须同时报告失败数量/原因。

## 7. 求解器认证与允许表述

每次 ECP-RH 重规划记录：

- `visibility_level_certified`；
- `overlap_level_certified`；
- `search_level_certified`；
- `execution_level_certified`；
- `priority_certified`；
- solve time / timeout / MIP gap。

允许写法：

- “在该重规划时刻，Level-1 MILP 在当前候选集合内被认证为最优”；
- “测试范围内的数值结果与理论趋势一致”；
- “在给定计算预算内获得可行 incumbent”。

禁止写法：

- 把有限候选集最优写成连续动作空间全局最优；
- solver timeout 时仍称最优；
- 把 Monte Carlo 结果称为“证明”理论；
- 把 OOD 没有改变模型误差的实验称为 robustness。

## 8. 论文完成前的闭环检查清单

| 检查项 | 完成标准 |
|---|---|
| 理论有实验 | 每个主要理论/方法主张至少有对应指标和场景 |
| 实验有理论问题 | 删除只“好看”但不回答研究问题的图表 |
| 指标一致 | 理论讨论 loss/revisit/risk 时，实验必须直接报告对应量 |
| baseline 公平 | 参数、信息、动作能力、seed、执行模型可审计 |
| 随机可靠 | 所有随机比较采用多 seed/Monte Carlo |
| 求解状态透明 | timeout、gap、certification 不隐藏 |
| 发现失败透明 | missed-target rate 和 censored delay 必报 |
| 数据可复现 | config、seed、raw CSV、plot data、代码 commit、环境版本齐全 |
| mirror 边界清楚 | 实机只镜像动作，真实视频不参与虚拟任务评价 |

当完整 Monte Carlo 跑完后，应把本表最后一列更新为“支持 / 不支持 / 证据不足”，再据此决定论文中哪些主张保留、降级或删除。

# `research/ecp-rh-experiments` 运行与复现实验说明

本分支用于“固定式多光电设备协同持续搜索与目标连续监视”研究。目标、检测、匿名目标信念、搜索 freshness 和论文评价均为软件虚拟任务。4 台真实 ZR10 仅在 `mirror` 模式下镜像执行 A/E/Zoom，不提供论文任务的检测或真值。

## 1. 安装

在仓库根目录进入：

```powershell
cd zr10_cooperative_lab
python -m pip install -r requirements.txt
```

只使用模型方法时不需要 PyTorch。若需要 MAPPO/Safe-MAPPO：

```powershell
python -m pip install -r requirements_research.txt
```

建议实验前记录：

```powershell
git branch --show-current
git rev-parse HEAD
python -m pytest -q tests/test_research_search_monitor.py tests/test_research_cadence.py tests/test_research_priority_metrics.py tests/test_research_protocol.py
```

每个研究 run 还会自动保存 `research_provenance.json`。

## 4. Mirror：虚拟任务 + 真实 ZR10 动作镜像

**以下命令会真实驱动 ZR10。没有完成网络、方向、限位和急停检查前不要运行。**

```powershell
python -m zr10lab.research.console `
  --config configs/research/search_monitor_base.yaml `
  --mode mirror `
  --algorithm ecprh `
  --arm
```

Mirror 中：

- 虚拟 ZR10 状态仍决定论文任务结果；
- 相同 A/E/Zoom 指令同步送往真实 ZR10；
- 真实姿态反馈只作为 diagnostics/telemetry 保存；
- 真实 RTSP/YOLO 不参与虚拟目标发现和跟踪；
- 页面预览会明确标记为 synthetic task view。

因此 Mirror 只能表述为“真实设备动作接口/执行展示”，不能写成真实目标检测实验。

## 8. 消融实验

例如：

```powershell
python -m zr10lab.research.studies ablation `
  --scenarios configs/research/scenarios/S10_heldout_mixed.yaml configs/research/scenarios/S11_heldout_handoff_contention.yaml `
  --ablations `
    configs/research/ablations/no_uncertainty.yaml `
    configs/research/ablations/no_overlap.yaml `
    configs/research/ablations/fixed_zoom.yaml `
    configs/research/ablations/short_horizon.yaml `
    configs/research/ablations/no_event_replan.yaml `
    configs/research/ablations/no_execution_model.yaml `
    configs/research/ablations/no_shared_fov.yaml `
  --seeds 3001 3002 3003 3004 3005 `
  --output runs/ablations
```

`no_execution_model` 只让**规划器**错误地认为动作瞬时到位；真实仿真转速和 settle 不变，因此能隔离执行感知规划的贡献。

示例：风险预算

```powershell
python -m zr10lab.research.studies sensitivity `
  --scenarios configs/research/scenarios/S4_boundary_handoff.yaml configs/research/scenarios/S8_maneuver.yaml `
  --path policy.research.planning.visibility_risk `
  --values 0.01 0.025 0.05 0.10 0.20 `
  --seeds 2001 2002 2003 2004 2005 `
  --output runs/sensitivity_risk
```

风险敏感性必须同时查看：

- `research_empirical_risk_violation_rate`
- monitoring loss / max gap
- revisit age
- solver/candidate cost

不能只用一个平均 tracking 指标声称概率保证成立。

## 11. MAPPO / Safe-MAPPO

训练示例：

```powershell
python -m zr10lab.research.mappo_protocol train `
  configs/research/scenarios/S1_single.yaml `
  configs/research/scenarios/S2_staggered.yaml `
  configs/research/scenarios/S3_crossing.yaml `
  configs/research/scenarios/S5_cluster_split.yaml `
  configs/research/scenarios/S6_contention.yaml `
  --output runs/mappo_seed1001 `
  --seed 1001 `
  --updates 300 `
  --rollout-steps 256 `
  --checkpoint-every 25
```

Safe-MAPPO 加 `--safe`。

checkpoint 选择只能使用 validation：

```powershell
python -m zr10lab.research.mappo_protocol select `
  runs/mappo_seed1001/*.pt `
  --configs configs/research/scenarios/S4_boundary_handoff.yaml configs/research/scenarios/S8_maneuver.yaml `
  --seeds 2001 2002 2003 2004 2005 `
  --output runs/mappo_seed1001_selection
```

选定 checkpoint 后，把路径写入：

```yaml
policy:
  research:
    baselines:
      mappo:
        model_path: <selected checkpoint>
        device: cpu
```

不要从多个训练 seed 中挑“最好 seed”作为唯一结果。正式比较应保留多个训练 seed，或者预先声明固定训练 seed；test 集不能用于 checkpoint 选择。

## 13. 正式实验前必须确认

1. CI/pytest 全部通过；
2. Weighted RH 权重已经只在 validation 冻结；
3. MAPPO checkpoint 已只在 validation 选择；
4. test_main/test_ood 配置和 seed 不再修改；
5. 论文中的 real-hardware 描述只写 mirror A/E/Zoom 执行，不写真实目标检测；
6. 如使用 ZR10 的真实执行速度/settle 数值，必须先从实机反馈重新识别，不直接引用仿真默认值；
7. 完整 Monte Carlo 完成前，`docs/理论实验闭环检查.md` 中标为“待完整实验”的结论不能提前写成已支持。

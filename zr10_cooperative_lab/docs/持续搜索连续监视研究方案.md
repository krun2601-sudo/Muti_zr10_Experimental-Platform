# 固定多 PTZ 持续搜索与连续监视研究方案

> 分支：`research/ecp-rh-experiments`
>
> 本文档定义论文实验的任务语义、软件边界和公平性约束。它与原平台的“多站协同定位”任务并存，不改变原有 `scan/center/multi` 模式的含义。

## 1. 研究任务

四台固定 ZR10 覆盖给定三维任务区域。目标的数量、进入时刻和运动轨迹在调度前未知。系统需要同时完成：

1. **持续搜索**：未被监视任务占用的设备反复扫描任务区域，限制区域重访年龄并尽早发现新目标；
2. **连续监视**：目标一旦被发现，在其离开任务区域之前，尽可能保证任意时刻至少一台设备对该目标具有有效视场；
3. **资源协调**：A/E 转动、Zoom 变化和到位稳定都会占用有限的 sensor-time；搜索、已知目标监视和跨设备交接竞争同一资源。

本研究不要求目标同时被两台设备观测，也不把双站三维定位作为任务成功条件。原平台 `center/multi` 的双站定位逻辑不能直接作为本文任务约束。

## 2. 虚拟目标与真实 ZR10 的边界

论文实验以**虚拟世界为任务真值源**。即使接入四台真实 ZR10，以下内容仍由软件产生：

- 目标产生、进入、退出和运动；
- 目标是否落入虚拟相机有效视场；
- 检测概率、测量噪声、跟踪不确定度和虚拟目标身份连续性；
- 持续搜索 freshness/revisit 状态；
- 调度算法输入；
- 论文评价指标与真值统计。

真实 ZR10 在本文实验中只承担**动作执行镜像**：接收与虚拟设备相同的 `yaw_deg / pitch_deg / zoom` 指令并实际转动。真实 RTSP 视频、YOLO 检测和真实图像内容不参与本文虚拟目标实验的任务闭环。

因此需要区分三种环境：

| 环境 | 目标/检测/跟踪 | 设备状态用于论文闭环 | 是否向真实 ZR10 发动作 |
|---|---|---|---|
| `sim` | 虚拟 | 虚拟设备 | 否 |
| `mirror` | 虚拟 | **虚拟设备（权威）** | 是，仅镜像 A/E/Zoom |
| `hardware` | 原平台真实视频/检测/融合 | 真实设备 | 是 |

`mirror` 必须显式 `armed` 才能运动真实设备。真实反馈单独记录，用于检查指令执行误差，但不改变虚拟目标是否被发现、是否持续可见以及论文主指标，从而保证 `sim` 和 `mirror` 的算法实验具有相同任务定义。

## 3. 信息隔离

研究算法不得读取虚拟真值。虚拟真值只进入：

- 虚拟感知生成器；
- 论文评价器；
- CSV/回放中的 `truth` 表。

算法只读取：

- 当前虚拟设备遥测（A/E/Zoom、角速度、可用状态）；
- 已发现目标的匿名 `track_id`、估计位置/速度、协方差、最近一次有效观测时刻和当前观测设备；
- 搜索网格 freshness/age；
- 已知的任务区域、相机模型和设备执行模型。

内部允许保存 `truth_id -> anonymous_track_id` 映射用于虚拟跟踪器，但该映射不得进入 `PolicyContext`、学习 observation 或算法 diagnostics。

## 4. 感知抽象

本文研究的是**主动观测资源调度**，不是检测器/ReID 算法。因此虚拟感知层作为受控实验条件：

1. 未发现目标只有在至少一台“可感知”设备的有效 FOV 中，并通过配置的检测概率模型后，才创建匿名 track；
2. 已发现目标只要被至少一台有效设备看见，就获得一次带噪声的测量更新；
3. 无有效观测时，track 按运动模型外推并扩张协方差；
4. 超过配置的 coast 时间后 track 可被标记为失联，但评价器仍依据隐藏真值统计真实失视；
5. 所有比较方法使用同一虚拟感知模型与随机种子。

为了避免不同策略因随机数调用次数不同而得到不公平的检测序列，实验默认采用**按 `(seed, truth_id, time_bin, device_id)` 确定的可复现随机采样**，而不是共享一个随调用顺序推进的 RNG。

## 5. 执行模型

动作不是瞬时生效。研究执行模型至少包含：

- A/E 最大角速度；
- Zoom 最大变化速率或标定的切换时间；
- 角度到位容差；
- Zoom 到位容差；
- 到位后的稳定时间 `settle_s`；
- 可选执行时间扰动（仅用于鲁棒性实验）。

设备在 slew / zoom transition / settling 期间不计为“有效观测”，除非某一实验显式配置 `allow_sensing_while_moving=true` 并说明其物理依据。

`mirror` 环境下上述虚拟执行模型仍决定论文任务闭环；真实 ZR10 的反馈另行记录。

## 6. ECP-RH 方法

最终主方法为 **ECP-RH: Execution-Constrained Priority Receding-Horizon Scheduling**。

核心是连续可见性优先的 sensor-time 分配。每个候选观测原语包含目标 A/E/Zoom、预计 ready 时间和有效 sensing interval。调度在有限预测时域内按词典序处理：

1. `J1`：最小化已发现目标的失视代价；
2. 在 `J1` 最优值不变的条件下，最大化持续搜索 freshness/revisit 效用；
3. 在前两级最优值不变的条件下，最小化执行/切换代价。

候选原语由物理可达的目标跟踪视角、交接视角和高 freshness 搜索视角生成。四台设备规模下优先使用 SciPy/HiGHS MILP 精确或有时间上限地求解，不把次模贪心作为主方法。

### 6.1 连续可见风险约束

已发现目标使用预测均值和协方差构造风险受限角域包络。风险在预测步和 A/E 方向之间显式分配，并预留采样间目标最大角运动裕度。理论主张只在给定预测误差模型成立的条件下给出。

### 6.2 预测重叠交接

交接不是“源相机先丢失，再由目标相机搜索”。源/目的设备的有效 sensing interval 必须至少重叠 `handover_overlap_s`。执行时间不确定时再加时间裕度。

### 6.3 多目标共享 FOV

候选原语允许一个设备同时满足多个目标的可见约束。不能人为限定“一台设备只能跟一个目标”。

## 7. 公平基线

所有方法必须使用同一虚拟世界、感知模型、设备限制、候选动作能力、决策周期和测试种子。不得向任一 baseline 泄漏真值。

计划实现：

1. `fixed_scan`：固定分区/周期扫描 + 反应式目标接管；
2. `greedy`：单步即时收益最大化；
3. `weighted_rh`：与 ECP-RH 共享预测/候选原语的加权滚动时域优化；
4. `classical_ptz`：受经典 constrained collaborative PTZ 思路启发的跟踪风险/搜索收益加权配置；
5. `ssm_pomdp`：有限候选动作上的 simultaneous-search-monitoring belief/look-ahead 近似；
6. `info_planner`：discovery/tracking 信息价值的多目标贪心规划近似；
7. `mappo`：本文任务专用 CTDE 学习基线；
8. `safe_mappo`：MAPPO-Lagrangian（或等价约束策略）基线；
9. `ecprh`：本文方法。

其中 4–6 是**按本文统一执行模型进行的可复现实验适配**，不得在论文中错误声称为原论文官方代码的逐行复现。适配差异必须记录。

## 8. 实验场景

至少包含：

- `S0-no-target`：无目标，验证持续搜索/revisit；
- `S1-single`：单目标、不同进入时刻；
- `S2-staggered`：2–4 目标错峰进入；
- `S3-crossing`：目标交叉/近距离经过；
- `S4-boundary-handoff`：沿视场/设备责任边界运动，重点验证交接；
- `S5-cluster-split`：多个目标先聚集后分离，验证共享 FOV；
- `S6-contention`：中高资源竞争；
- `S7-overload`：5–6 个空间分离目标，明确系统容量超载；
- `S8-maneuver`：分段机动/转弯；
- `S9-ood`：目标速度、执行时延、Zoom 速率等偏离训练/标称配置。

每个随机场景保存种子和实际生成的目标参数。模型方法与学习方法使用严格分开的 train/validation/test 场景集合。

## 9. 指标

### 搜索
- 目标发现率；
- 发现延迟 mean/median/P95；
- 初次完整覆盖时间（次要）；
- 网格重访时间 mean/P95/max；
- freshness/AoI 积分。

### 连续监视
- target visible ratio；
- total loss duration；
- maximum continuous loss gap；
- loss episode count；
- handover success rate；
- handover overlap duration / reacquisition delay。

### 执行
- slew/zoom/settle 占用时间；
- 有效 sensing duty cycle；
- 总角运动/Zoom 变化；
- task switch count。

### 算法
- decision time mean/P95/max；
- deadline/solver timeout rate；
- MILP success/status/gap（能获得时）；
- infeasibility/slack。

## 10. 理论—实验映射

| 理论/方法主张 | 所需证据 | 实验 | 主要指标 |
|---|---|---|---|
| 第一优先级在同一候选原语集合上最优 | 同场景、同原语，与 weighted/greedy 对比；小规模检查 solver optimum | contention / handoff | `J1`, loss duration, solver status/gap |
| 风险受限可见性 | 多 Monte Carlo 噪声，改变风险预算 | uncertainty sweep | empirical violation rate, visible ratio |
| 重叠交接充分条件 | 有/无 overlap 与不同执行扰动 | boundary-handoff | handover success, max gap, overlap |
| 持续搜索而非一次覆盖 | 无目标/随机进入与不同重访策略 | no-target / staggered | revisit P95/max, detection delay |

实验只能表述为“与理论预测一致”“数值结果支持上述分析”，不得称为实验“证明”定理。

## 11. 可复现数据

每个 run 至少保存：

- 完整解析配置；
- Git commit/branch；
- scenario ID、seed、method、method parameters；
- 隐藏真值；
- 匿名目标 belief；
- 每台设备虚拟状态和（mirror 时）真实反馈；
- 动作与原语选择；
- 每步搜索 freshness 摘要；
- 每目标可见/失视/发现状态；
- solver diagnostics；
- 周期计算耗时；
- 汇总指标；
- CSV 哈希清单；
- 环境/依赖版本。

批量实验生成 `index.csv` 和独立的 aggregate/plot-ready 表，图表必须由保存的数据重新生成，而不是手工抄数。

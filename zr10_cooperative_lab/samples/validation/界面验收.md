# 总控制中心浏览器验收

2026-09-07，在 Windows 本机 Codex 浏览器中操作真实启动的 HTTP 控制中心，使用仿真环境；没有连接 ZR10 或加载用户 YOLO 权重。

- 默认 1280×720 视口：完整页面无水平溢出；三维场景正常渲染，控制台未出现 JavaScript/WebGL 错误。实际完整页面截图见 `docs/control_center_preview.png`。
- 多目标协同定位：四台模拟设备在线，出现两个定位轨迹，遥测及视场更新。
- 视频：开启后四张预览均加载 640×360 图像，关闭后界面停止预览。直接操作可访问性 switch 控件通过。
- 手动：25 号设备输入 A=12°、E=15°、倍率=2，反馈到达目标；“停止本台”显示停机锁定，“交回算法”恢复策略控制。
- 状态：暂停、继续、切换扫描模式、急停和解除急停通过；解除后仍处于暂停，不自动运动。
- 模式：中心跟踪定位、固定姿态定位、单站图像跟踪可启动；2 秒实验按时结束。
- 配置：停止后修改站点 X 坐标并应用，随后恢复原坐标；保存 YAML 成功，校验用副本保存在本地 runs 中，不作为默认配置交付。
- 三维：俯视、复位及图像导出操作无浏览器错误；关键标签具有最小屏幕尺寸。
- 心跳：运行时离开页面，HTTP 快照确认状态自动进入 paused；轨迹带有最多 300 点的 history_samples，保存测量/预测来源。
- 安装产物：wheel 构建成功，逐字节核对其中 9 个前端及 Three.js 文件与工程源码一致。压缩包不包含虚拟环境、模型权重和本地 runs。

自动化测试和五个固定仿真场景的结果另见同目录 `验收报告.md` 与 `VERIFICATION.json`。仿真精度及计算周期不能替代现场图像、网络、云台响应、标定及 YOLO 推理性能测试。
